# 2026 festival calendar imports

Prepared on 29 September 2026: **24 new events** for Melbourne International Games Week and Sydney Games Festival. Compared against the [26 September export](../documentation/aus_games_events_2026-09-26.ics). **Import status: prepared; live import not confirmed.**

Import [the combined batch](2026-festival-new-events.ics) once, or choose individual files below. The batch and individual versions use the same event UIDs; choose one route and avoid importing both.

In Google Calendar on a computer, use **Settings → Import & export**, select the file, and select the shared **Game Developers of Australia** calendar as the destination. Check the imported titles, dates, locations and links. [Google import instructions](https://support.google.com/calendar/answer/37118?hl=en). These files do not publish events themselves, and importing them does not establish an ongoing sync.

High Score (3–4 October) and GCAP (5–7 October) are single multi-day all-day entries, as requested. Play Now is a date-only entry on 8 October: its public pages do not specify attendance hours or a venue. Timed events use UTC instants converted from Melbourne/Sydney local time, including the 4 October daylight-saving change. Beer and Pixels is a one-off festival entry because the existing series explicitly excludes its October occurrence.
